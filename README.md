Download Full RAR File Here: https://github.com/MrrZed0/youtube-downloader/releases/tag/youtube


Files Needed To Make This Work:

- Download yt-dlp (yt-dlp.exe)
  https://github.com/yt-dlp/yt-dlp

- Download Deno (denort-x86_64-pc-windows-msvc.zip)
  https://github.com/denoland/deno/releases

- Download FFMPEG (ffmpeg-git-full.7z)
  https://www.gyan.dev/ffmpeg/builds/

  1) Extract Everything To The yt-dlp Folder
  2) Edit playlist.txt File In Notepad
  3) Add YouTube Playlist URL On Each Line In playlist.txt
  4) Run the run-playlist.bat to download mp3 - Run the run-video-playlist.bat to download mp4 video
